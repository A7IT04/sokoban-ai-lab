# Contributing

1. Fork the repository and create a descriptive branch.
2. Use Python 3.10+ and run `python -m unittest discover -s tests -v`.
3. For RL changes install `.[rl]` and include seed, algorithm, steps and evaluation data. Report failed runs too.
4. Add tests for new behavior and use original or properly licensed assets only.
5. Submit a focused pull request describing the change and its limitations.
